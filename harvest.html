เก็บลิงก์ GitHub จาก Facebook

สแกนโพสต์ที่แชร์ไว้บนโปรไฟล์ รวมลิงก์ที่อยู่ในคอมเมนต์ของคนโพสต์ต้นทาง

  1. กด คัดลอกสคริปต์ ด้านล่าง
  2. เปิด หน้าโปรไฟล์ Facebook ของคุณ บนคอมพิวเตอร์ (Chrome หรือ Edge)
  3. กด F12 (Mac: Cmd+Option+J) แล้วเลือกแท็บ Console
  4. วางสคริปต์แล้วกด Enter ถ้าวางไม่ได้ ให้พิมพ์ allow pasting แล้ว Enter ก่อน แล้ววางใหม่
  5. ปล่อยให้เลื่อนเอง จะมีกล่องสถานะมุมขวาล่าง พอรอบแรกเสร็จ กด เปิดดูคอมเมนต์ ถ้าเบราว์เซอร์ถามเรื่อง pop-up ให้กดอนุญาต
  6. เสร็จแล้วกด คัดลอกผลลัพธ์ แล้ววางในแชทกับ Claude
